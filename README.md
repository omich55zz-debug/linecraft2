# Linecraft 2

L2-style 3D RPG в браузере: 6 рас (человек, эльф, тёмный эльф, орк, гном, камаэль) × 2 класса каждая, вид сверху с зумом, click-to-move, авто-атака, монстры с HP-бараами, level-up.

## Стек
- Three.js + Vite (без бандл-серверов / без БД на старте — всё в браузере)
- PWA (manifest + service worker, играется офлайн)
- Capacitor для Android APK сборки через GitHub Actions

## Скрипты
```bash
npm install
npm run dev       # localhost:5173
npm run build     # dist/
npm run icons     # генерация иконок 192/512
```

## Управление
- **ЛКМ** по земле — идти; **ЛКМ** по монстру — выбрать как цель + атаковать
- **ПКМ + drag** — вращать камеру; **колесо** — зум
- **1** — атака, **2** — силовой удар (8 MP), **3** — лечение (12 MP), **R** — сесть/восстановить
- **Esc** — снять цель
